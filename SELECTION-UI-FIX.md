# Calm selection UI fix

- Selection controls no longer replay the whole stage animation or force the wizard scroll to the top.
- Category, age/space, tri-state and dynamic multi-select controls update in place.
- Tools use two graphical mode cards. After choosing a mode the cards collapse into compact rows and selected tools are shown at the bottom.
- Goals use a graphical searchable card grid; selecting/removing goals updates in place and selected goals are shown below the chooser.
- Occasions start with two graphical choices: "همه مناسبت‌ها" and "انتخاب مناسبت". After choosing, the cards collapse. Specific occasions can be searched/filtered and selected items are shown below.
- Stage transitions remain only for moving between wizard steps and are reduced to a short calm fade.
